# Neon Horizon documentation

Neon Horizon is a small procedural 3D arcade racer made with Rust stable and Bevy 0.19. It uses a single rectangular loop, one player car, a one-lap finish trigger, and a vaporwave-inspired procedural environment.

## Start here

- [Getting started](getting-started.md) — install prerequisites and run the game.
- [Architecture](architecture.md) — understand the ECS modules, plugins, and game states.
- [Gameplay systems](gameplay.md) — learn how movement, boundaries, timing, and finish detection work.
- [Assets and extension](assets-and-extension.md) — replace procedural content with GLB files and add future features.

The project intentionally keeps its world scale simple: **one Bevy world unit is approximately one metre**.
